# Optional blank CSV logs and text templates

These are **empty templates**, not completed evidence. Each CSV has only a header row; any content entered later belongs in a **private household folder**, not the public repository. Do not create or commit filled-in logs, names, private addresses, photo metadata or original source files here.

For most neighbors, the [printable event form](../print/03_Event_Observation.pdf), [media index](../print/04_Photo_and_Video_Index.pdf), and [request tracker](../print/10_Request_and_Response.pdf) are enough. The full [18-page packet](../print/Tom_Street_Neighbor_Documentation_Forms.pdf) has additional optional worksheets.

| Blank template | What to track |
| --- | --- |
| `OBSERVATION_LOG.csv` | Firsthand events, time, location, limits and related evidence |
| `PHOTO_VIDEO_INDEX.csv` | Original files, source, capture date, derivatives and permission |
| `REQUEST_TRACKER.csv` | Draft, sent, acknowledged, partial and received communications |
| `SOURCE_DOCUMENT_LOG.csv` | Plans, permits, surveys, inspection notes and revisions |
| `DOCUMENTED_ROLE_TRACKER.csv` | Specific roles connected to sources and features |
| `DRAINAGE_FEATURE_LOG.csv` | Individual pipes, swales, inlets and outlets |
| `WORK_AND_CONDITION_LOG.csv` | Observed work, recorded status and later conditions |
| `ORIGINAL_FILE_AND_TRANSFER_LOG.csv` | Original custody and who received a copy when |
| `WEATHER_AND_COMPARISON_LOG.csv` | Rainfall source, observation times and storm comparability |
| `PROPERTY_CONDITION_AND_EXPENSE_LOG.csv` | Private property effects, actions and receipts |
| `MEETING_NOTES.md` | Private conversation or inspection follow-up |
| `CHANGE_AND_CORRECTION.md` | Reviewed changes to public claims, with evidence and approval |

Keep dates in a clear, consistent format (`YYYY-MM-DD`) and times with a named time zone or offset. Use "unknown" when the information cannot be established. A blank field does not mean "none". For IDs and originals, see [the short guide](../05_ORIGINALS_AND_IDS.md).
