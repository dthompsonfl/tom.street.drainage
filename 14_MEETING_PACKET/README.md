# SUPERSEDED / WITHDRAWN FROM DISTRIBUTION

The PDFs in this directory are **historical drafts**. Some contain interpretations subsequently corrected, including statements about as-built certificates and roadside pipes that were not proved by the preserved records.

**Do not hand out or cite these PDFs as the current Tom Street packet.** Use the [current draft handouts](../15_RECONCILED_DRAFTS/README.md) and [plain-English evidence guide](../PUBLIC_EVIDENCE_GUIDE.md). The historical bytes remain available for version tracking and research accountability; they have **not** been certified factually accurate by retaining them.
